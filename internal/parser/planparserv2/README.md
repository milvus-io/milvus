# Generate Parser with Antlr4 and galop

## Install the tools

Please follow [install antlr4](https://github.com/antlr/antlr4/blob/master/doc/go-target.md) to install the antlr tool.

The version of antlr tool: `4.13.2`.

The lexer and parser that parse expressions are generated by
[galop](https://github.com/martianoff/galop) from the same `Plan.g4`. Download a
release binary from its [releases](https://github.com/martianoff/galop/releases)
and put it on `PATH` as `galop`.

The version of galop: `0.9.0`.

## Code Generate

After you install both tools, you can generate the parser code in golang with:

```shell
go generate
```

All generated code will be under directory `generated`: ANTLR's lexer, parser and
visitor, and galop's `PlanGalopLexer` and `PlanGalopParser`, which build ANTLR's
contexts and report ANTLR's errors to the error listeners, so the visitor works
with them unchanged.
