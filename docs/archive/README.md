# Archived Milvus documentation

This directory contains superseded documentation retained for historical
context. It is not a source of current Milvus behavior or contributor rules.

- [`milvus-2.0/`](milvus-2.0/) contains early Milvus 2.0 architecture,
  developer, Segcore, and tracing material.
- [`milvus-2.5-2.6/`](milvus-2.5-2.6/) contains documents tied to the Milvus
  2.5-2.6 implementation period.

When using archived material, verify every claim against current source code
and current documentation.
