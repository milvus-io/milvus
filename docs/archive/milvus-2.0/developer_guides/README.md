# Historical Milvus 2.0 developer guide

This directory is the archived form of the former
`docs/developer_guides/` tree. It describes an early Milvus 2.0 architecture
and is retained so old links and design records still have historical context.

The original entry point is [`developer_guides.md`](developer_guides.md).
Individual chapters cover the system overview, schema, coordinators, proxy,
message streams, and binlog format. The appendices and figures belong to the
same historical manual.

This material is non-normative. For current engineering guidance, use:

- [`docs/agent_guides/`](../../../agent_guides/) for current subsystem
  architecture and debugging guidance;
- [`docs/dev/`](../../../dev/) for current contributor procedures.
