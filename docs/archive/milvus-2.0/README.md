# Milvus 2.0 documentation archive

This directory preserves early Milvus 2.0 developer and tracing guides. The
documents refer to components and workflows that have since changed or been
removed, including the original IndexCoord/IndexNode architecture, the early
Segcore interfaces, and the OpenTracing-based tracing setup.

Use current subsystem guidance under `docs/agent_guides/` and current developer
rules under `docs/dev/` instead.

- [Milvus 2.0 Developer Guide index](developer_guides/README.md)
- [OpenTracing and Jaeger guide](jaeger_guides/opentracing_user_guide.md)
- [Early Segcore notes](segcore/segment_overview.md)

The archived Developer Guide's [`figs.graffle`](developer_guides/figs/figs.graffle)
file is retained as the editable source for its historical architecture
diagrams.

The archived Segcore notes describe the 2021-2022
segment and query implementation and must not be treated as current interfaces.
