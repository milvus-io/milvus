# Milvus 2.0 documentation archive

This directory preserves documentation written for the early Milvus 2.0
architecture. Names such as `indexcoord`, `querycoord`, and the original
Segcore interfaces reflect that historical implementation and may no longer
match the current repository.

- [`developer_guides/`](developer_guides/) contains the former
  `docs/developer_guides/` architecture manual and its figures.
- [`segcore/`](segcore/) contains the former Segcore design notes that had been
  mixed into the formal Design Doc tree.
- [`jaeger_guides/`](jaeger_guides/) contains the former OpenTracing/Jaeger
  guide and screenshots.

Use current subsystem documentation under `docs/agent_guides/` for active
development.
