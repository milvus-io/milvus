GC 生命周期

先停止 writer，再经过保留期和静默窗口删除完整作业根目录

RUNNING
保留选中和未选中结果、attempt 内工作对象、计划与结果 manifest
→
TERMINAL / QUIESCING
Completed / Failed 后立即保存清理记录，并精确 Drop 当前 attempt
→
RETENTION
taskRetention 只延迟对象和 catalog 删除，便于诊断
→
DELETING
对带结尾斜线的完整数字作业根目录幂等执行 RemoveWithPrefix
→
VERIFYING
保留清理记录；周期性 LIST/Walk + 重复清扫
→
DONE
完整 missingTolerance 静默窗口内未再观察到对象
若 VERIFYING 又看到迟到写入的对象：回到 DELETING 并重新开始静默窗口；不能只靠对象 mtime 猜测已安全。
