# Temporary user guides

The canonical Milvus product documentation is maintained in
[`milvus-io/milvus-docs`](https://github.com/milvus-io/milvus-docs).

This directory is temporary staging for feature documentation that has not yet
been published there. A guide should be removed from this repository after its
maintained version is available in `milvus-docs`. User guides do not satisfy the
feature Design Doc requirement and are not formal Design Docs.

- [Clustering Compaction](clustering_compaction.md)
- [Collection TTL](collection_ttl.md)
- [External Table](external_table.md)
- [Snapshot](snapshot_user_guide.md)
- [TLS for Proxy](tls_proxy.md)
- [Per-Cluster mTLS for CDC Cross-Cluster Replication](cdc/06-cdc-per-cluster-mtls.md)

Legacy CDC user documentation remains under the historical Design Doc tree
until its publication and migration status is confirmed.
